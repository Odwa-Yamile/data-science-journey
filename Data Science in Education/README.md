
# 📚 Data Science in Education

This folder contains my coursework, practical exercises, assignments, and projects completed for the **COMS5023A: Data Science in Education** module at the **University of the Witwatersrand (Wits University)**.

The module focuses on using data to support educational decision-making through database management, data analysis, and business intelligence. My work in this folder demonstrates practical skills in **SQL** and **Power BI**, which are key tools for managing, analysing, and visualising educational data.

## Current Contents

### SQL

This section contains:

* SQL practical exercises
* Database creation and table design
* Data Definition Language (DDL) commands
* Data Manipulation Language (DML) commands
* Data querying, filtering, sorting, and aggregation
* Database assignments and projects completed using SQL Server Management Studio (SSMS)

### Power BI

This section contains:

* Power BI practical exercises
* Data loading and transformation
* Data cleansing
* Interactive dashboards
* Reports and visualisations
* Power BI assignments and projects

This repository will continue to be updated as I complete additional coursework and projects throughout the module.
