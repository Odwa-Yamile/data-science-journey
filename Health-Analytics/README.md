# Health Analytics for Data Science & Health Analytics

## 📖 About This Repository

This repository contains my practical labs, Python notebooks, analyses, and coursework for the Health Analytics modules.

The courses combine **health sciences, data science, statistics, data visualisation, epidemiology, and machine learning** to analyse healthcare data and address real-world health problems.

The practical work focuses on preparing and analysing health datasets and using analytical and machine learning methods to produce meaningful insights that can support healthcare decision-making.

## 🎯 Course Objectives

Through these courses, I am developing skills in:

- Understanding different sources and types of health data
- Data cleaning and preparation
- Data validation and quality assessment
- Exploratory Data Analysis (EDA)
- Data visualisation
- Descriptive and statistical analysis
- Framing healthcare problems as analytical questions
- Supervised machine learning
- Unsupervised machine learning
- Evaluating machine learning models
- Interpreting analytical results in a healthcare context
- Communicating findings using tables, graphs, and reports
- Understanding health data privacy, ethics, responsible AI, and bias

## Topics Covered

The course curriculum includes:

1. Introduction to Health Systems & Health Analytics
2. Data Preparation, Exploratory Data Analysis & Visualisation
3. Introduction to Machine Learning in Health Analytics
4. Linear Regression
5. Logistic Regression
6. Decision Trees
7. K-Means Clustering
